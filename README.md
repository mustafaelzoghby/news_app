# news_app

> Flutter News App -- categorized news with bilingual (AR/EN) and Light/Dark mode support

---

## About

Flutter-based mobile application displaying latest news articles categorized by topic. Supports English and Arabic with Light/Dark mode. Built by [Mustafa Mahmoud](https://mustafa-mahmoud.vercel.app).

### Key Features

- Categorized news (Sports, Tech, Health...)
- Arabic & English language support
- Light & Dark mode
- Article search with News API

## Tech Stack

| Technology | Version |
|-----------|---------|
| Flutter | >=3.0.0 |
| Dart | >=3.0.0 |
| News API | v2 |
| Light/Dark | Mode |
